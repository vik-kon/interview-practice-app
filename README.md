# Interview Practice App

A web application to help practice behavioral interview questions with voice recognition.

## Features

- Voice-to-text recording using Web Speech API
- Built-in timer to track response length
- Random question generation
- Add custom questions
- Real-time transcription of your answers

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Web Speech API

## Getting Started

### Prerequisites

- Node.js 22+ installed
- Chrome or Edge browser (for speech recognition)

### Installation

1. Clone the repository
```bash
git clone https://github.com/YOUR-USERNAME/interview-practice-app.git
cd interview-practice-app
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in Chrome or Edge

## Usage

1. Click "Start Recording" to begin answering a question
2. Speak your answer - it will be transcribed in real-time
3. Click "Stop Recording" when finished
4. Click "Next Question" for a new random question
5. Add your own questions using the input field at the bottom
